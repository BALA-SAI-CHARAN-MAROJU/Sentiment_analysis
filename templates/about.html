Sentiment Analysis on Social Media Posts

An intelligent, end-to-end Natural Language Processing system that automatically extracts, cleans, classifies, and evaluates the sentiment polarity (Positive, Negative, Neutral) of high-velocity social media texts and tweets using statistical machine learning architectures.

Python 3.14 Flask 3.x Scikit-Learn TF-IDF Vectorization SQLite3 Bootstrap 5 Chart.js
Problem Statement
Social media channels generate millions of informal posts every second containing abbreviations, colloquialisms, emojis, hashtags, and noisy orthography. Organizations, brands, and researchers face immense challenges manually deciphering public feedback and brand sentiment. This project addresses this limitation by engineering an automated, resilient NLP pipeline capable of accurately discerning sentiment polarity into Positive, Negative, and Neutral classes with measurable statistical confidence.
Project Objectives
  • Automate dataset acquisition without manual download overhead.
  • Build a robust preprocessing engine preserving emotional context in emojis and hashtags.
  • Train, benchmark, and compare multiple supervised & deep learning classifiers (Logistic Regression, Naive Bayes, Linear SVM, Multi-Layer Perceptron, and PyTorch Deep Neural Network).
  • Provide local explainability highlighting influential n-gram keywords per prediction.
  • Deliver an intuitive dashboard featuring live text inference, bulk CSV classification, and persistent SQLite tracking.

Mathematical Foundations
1. TF-IDF Formula

Measures the statistical importance of a word \(t\) in a post \(d\) relative to corpus \(D\):

TF-IDF(t, d, D) = TF(t, d) × IDF(t, D)
IDF(t, D) = ln((1 + |D|) / (1 + DF(t))) + 1
2. Multinomial Naive Bayes

Applies Bayes' Theorem under conditional feature independence assumption:

P(c|d) ∝ P(c) ∏ P(t_i | c)
Laplace smoothing: P(t|c) = (count(t, c) + α) / (∑ count(w, c) + α·|V|)
3. Linear SVM Margin

Finds maximum-margin hyperplanes separating sentiment classes:

min_w 0.5 ||w||^2 + C ∑ max(0, 1 - y_i(w^T x_i + b))
4. F1-Score Criterion

Harmonic mean balancing Precision and Recall across classes:

F1 = 2 × (Precision × Recall) / (Precision + Recall)
5. Deep Neural Network (PyTorch / Multi-Layer Perceptron)

Learns non-linear representations across hidden layers with Batch Normalization, ReLU activations, and Dropout regularization:

z[l] = W[l] a[l-1] + b[l],   a[l] = ReLU(BN(z[l]))
Cross-Entropy Loss with AdamW optimization: ℒ = -∑c yc log(σ(z)c) + λ ||W||2
Project Presentation / Viva Voce Q&A Cheat Sheet
Q1: Why did you not delete all emojis during text preprocessing?
A: In social media text, emojis carry vital emotional polarity. Blindly stripping emojis removes strong sentiment cues (e.g. 😍 or 😡). Our pipeline translates emojis into explicit descriptive sentiment tokens before tokenization.
Q2: Why use TF-IDF rather than simple Bag of Words (CountVectorizer)?
A: Simple Bag of Words assigns disproportionate weight to frequently occurring words. TF-IDF down-weights universally common terms and rewards distinctive discriminative keywords that distinguish positive from negative posts.
Q3: How was data leakage prevented during model training?
A: The dataset was split into training (80%) and testing (20%) sets using stratified sampling first. The TF-IDF vectorizer was fitted only on the training data (`fit_transform`) and subsequently used only to `transform` the test data.
